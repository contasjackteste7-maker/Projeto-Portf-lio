# FRAME — Vídeos Empresariais & Presença Digital

Landing page e portfólio de alta conversão para produtora audiovisual e gestão de redes sociais, com showcase interativo de vídeos, simulação de feed e perfil no Instagram e design cinematográfico dark luxury.

## 🚀 Tecnologias

- **Nuxt 4 / Vue 3**
- **HTML5, Modern CSS & Vanilla JavaScript**
- **Google Fonts (Bai Jamjuree)**
- **Uiverse.io** (Preloader animado)
- **Design System**: Dark luxury com gradientes obsidian, neon coral e amber

## 📦 Como rodar o projeto

### Modo Nuxt
```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento (http://localhost:3000)
npm run dev

# Gerar build de produção
npm run build
```

### Modo Estático
Abra o arquivo `index.html` diretamente em qualquer navegador ou sirva via Live Server / servidor estático.
